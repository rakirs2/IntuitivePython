# Monte Carlo methods with polygons

This is mostly for beginners who have experience programming other languages. Writ large, we're going to assume that the user has some knowledge of what code needs to be written and could maybe even write it in a different language but needs to be brought up to speed in order to do it in Python.

I'm mostly writing this as a starter for someone interested in dipping their toes into financial math. There's a ton of stats which, frankly, I do not know. Namely Martingales. 

## Objectives
### Python
- Ideally a light usage of "class" hierarchies
- Debugging
- Basic unerstanding of random.
- basic understanding of matplot lib
### Math
- Simple polygon construction
- Simple probability
- Stretch goal, rejection sampling

## End goal
Be able to answer if every regular polygon has a speciifc ratio with their inscribed circle.
